The inner integral evaluates to a regular part plus $g(\zeta_n)\log\frac{u_{max}-\zeta_n}{-u_{max}-\zeta_n}$. That log blows up (logarithmically) when the pole hits an endpoint of the inner interval: ζ_n(γ*) = ±u_max(γ*). This γ\* is the "rim branch point" — as a function of γ, the slice result H(γ, ω) has a log branch point there. Geometrically: the relativistic resonance curve γω − k∥p∥ = nΩ₀ is tangent to / crosses the p⊥ = 0 rim of the momentum sphere. Physically it's the onset threshold of harmonic n — the boundary in γ between "this shell resonates" and "it doesn't." It's the same structure that gives weakly-relativistic dispersion functions (Shkarofsky/Dnestrovskii) branch points where the nonrelativistic Z has none.
